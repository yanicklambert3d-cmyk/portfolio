# Portfolio - GitHub Pages

1. Criar um repositorio publico UTILIZADOR.github.io na conta GitHub.
2. Enviar o conteudo desta pasta para a raiz, incluindo assets e .nojekyll.
3. Settings > Pages > Deploy from a branch > main > / (root) > Save.
4. Testar https://UTILIZADOR.github.io.

Preparacao: 22 paginas HTML e cerca de 70 MB. Pasta original preservada. Foi acrescentado .nojekyll.
As referencias locais em HTML verificadas existem. Existem 31 referencias a imagens ausentes em CSS da exportacao; consultar referencias-em-falta.txt ao lado desta pasta. Podem pertencer a componentes sem uso.
O formulario depende do Smart Forms do Bootstrap Studio: testar o envio no site publicado.
Nao foi feita verificacao visual no navegador nem de servicos externos.
Nenhum repositorio foi criado e nenhum DNS foi alterado. Testar primeiro em github.io antes de ligar yanicklambert.com em Settings > Pages > Custom domain e configurar DNS.

Documentacao: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
