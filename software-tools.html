PROCESS & SYSTEM ARCHITECTURE

Plant Growth Platform: Design & system architecture

01 · RESEARCH CONTEXT

Idea & purpose

  • Extend Seed of Memories beyond VR.
  • Support daily plant care and reflection.
  • Collect diaries and follow-up responses.
02 · PARTICIPANT EXPERIENCE

Requirements & journey

  • Define one clear, three-step journey.
  • Provide English and Portuguese diaries.
  • Connect download, upload and questionnaire.
03 · BOOTSTRAP STUDIO · HTML / CSS / JS

Interface & prototype

  • Design the responsive interface.
  • Create language selection and progress states.
  • Prototype the original upload with PHP.
04 · GITHUB PAGES · SUPABASE

Migration & architecture

  • Deliver static pages and local PDF downloads.
  • Replace PHP uploads with Supabase Storage.
  • Connect the Microsoft Forms questionnaire.
05 · PRIVATE DIARY STORAGE

Storage & access

  • Accept PDF diaries up to 20 MB.
  • Generate dated names with unique codes.
  • Allow submissions without public diary access.
06 · INTEGRATED PARTICIPANT WORKFLOW

Validation & delivery

  • Validate downloads and confirmed uploads.
  • Advance the progress markers after each action.
  • Deliver the website through GitHub Pages.
